# VizLab v1.1 이후 — 남은 과제

## 목표 미달·미수행

1. **요청문 밖에서 새 후보 20개 이상 조사**: 0개. Data Mountain, Temporal Activity Map, Schoeller, Interleaved PES, Piper 3D도 조사하지 못함.
2. **도감 370(확장 목표)**: 360에서 멈춤. Hasse를 통합 대상으로 보면 359.
3. **원문 대조**: 모든 서지가 웹 기록 수준. 링 맵(Battersby 외 2011)의 저자·DOI, 이동시간 카토그램의 원 논문, 캑터스트리 배치 규칙, 직사각형 카토그램의 DOI 등을 출판사·저자 사이트에서 확인.
4. **이전 구현의 정확도**: 컨투어 트리(지속성 단순화, 큰 격자 성능), 윤곽 상자그림(원 논문의 상자 확대 울타리, 영역 단위 깊이), ZAME(전환 애니메이션), 이센트릭 라벨링(충돌 회피)은 손대지 못함. 스페이스트리는 새 노드가 부모에서 펼쳐지는 전환·카메라 이동이 없음.
5. **3,000노드 롱태스크**: 재현되는 문제를 찾지 못함. 10,000노드는 슬라이더 상한(3,000) 때문에 측정하지 못함. OffscreenCanvas 등은 시도하지 않음.
6. **WebGL**: 비교는 했으나 앱의 큰 입력(예: 큰 격자의 등치면)에서의 삼각형 수는 측정하지 못함. 상한 데이터에서 4만 개 이상이 되는 실험실이 있으면 도입 검토.
7. **연결(linking)**: 테일러·타깃·행렬 큐브(3D)·평행 간선 스플래팅·스폿 노이즈·스트림 리본·이동시간 카토그램·하세·피타고라스·캑터스트리(노드)·히스토리 플로는 행 단위 연결이 없음(데이터 공유뿐).
8. **구현 단순화 해소**: 연속 평행 좌표의 해석적 밀도, 연속 산점도의 n차원 일반화, 히스토리 플로의 텍스트 비교, 파이퍼의 K 분리·원 크기, 스티프의 네 번째 행, 스큐-T의 CAPE, 스폿 노이즈의 휘는 반점, 행렬 큐브의 셀 집계.
9. **Hasse 독립성**: dag-layout 실험실의 부분순서 모드로 통합할지 결정.
