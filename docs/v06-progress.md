## 이번에 만든 기법과 검증 방법

계산이 들어간 모든 차트는 엔진 함수를 따로 두고 **손으로 구한 값·교과서 예제·항등식**으로 단위 테스트했습니다. 예:

- 그래프 라플라시안: 경로 그래프의 고유값이 2 − 2cos(kπ/n)와 같음, 0 고유값 수 = 연결 성분 수.
- 최대 유량: CLRS 교재 그림 26.6의 값 23, 최대 유량 = 최소 절단 용량, 유량 보존.
- 루뱅: 두 클릭을 한 간선으로 이은 그래프에서 모듈성 Q = 2(10/21 − 1/4)와 정확히 일치.
- 임계 경로법, 수정 랜드 지수, 부자 클럽 차수 보존 무작위화(모든 차수 유지)를 손계산과 비교.
- 와이블: 직선 위의 자료에서 β, η를 소수 8째 자리까지 복원, 존슨 조정 순위 손계산, 최대가능도 점수 방정식 잔차 0.
- 공차 누적: 최악 경우 = 공차 합, RSS σ = √(Σσᵢ²), 정규 꼬리 확률 0.0027과 몬테카를로 비교.
- 대기행렬: 얼랭 C(2, 1.5) = 4.5/7, 시뮬레이션 평균 대기 ±12% 이내.
- 단백질: 이면각 IUPAC 부호, 골격을 NeRF로 쌓은 뒤 φ/ψ를 다시 계산해 입력과 6자리까지 일치.
- 이전 배치: t-SNE·UMAP(a, b 곡선 맞춤 = umap-learn 값), 정확한 Shapley, ALE, Metropolis·R̂·ESS, GEV L-모멘트, 크리깅, 정확한 이차계획, 블랙–숄즈·내재변동성 역산 등.

## 정직하게 밝혀 둘 한계

- 어텐션 맵은 **학습하지 않은 임의 가중치**이며 화면에 그렇게 표시합니다. 손실 지형은 2차원 등고선만 제공합니다.
- UMAP은 단순화한 변형(PCA 초기화, 정확한 k-최근접 이웃)입니다.
- 3차원 차트는 CPU/Canvas 렌더링이며 WebGL을 쓰지 않습니다.
- 모든 예제 데이터는 합성입니다. 실제 환자·유전체 자료를 쓰지 않았고 투자 조언 기능은 없습니다.
- 접촉 지도·라마찬드란의 골격 좌표는 이상적 기하로 쌓은 가상 펩타이드이며 실제 PDB 구조가 아닙니다. 라마찬드란 영역 상자는 대략적 구분입니다.
- 고장 수목은 기본 사건 18개 이하, 스펙트럼 임베딩은 노드 160개 이하, 블록 모형은 노드 120개 이하에서만 계산합니다.
- 실제 모바일 기기에서의 시험은 하지 않았고, Playwright의 모바일 뷰포트 에뮬레이션만 사용했습니다.
