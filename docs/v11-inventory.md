# VizLab v1.1 — 새 항목의 분류·구현 수준·독립성

도감: 340 → **360** (새 20개). 기존 340개의 id·URL·데이터셋·테스트는 그대로입니다.

## 1. 범용 방법론 13개와 전문 도표 7개

요청문의 원칙대로 전문 도표는 범용 방법론과 구분해 셉니다. 범용 방법론은 `kinds.ts`에서 ‘기법(technique)’, 전문 도표는 ‘전문 도표(specialized)’로 분류했습니다.

- **범용 표현 방법론(13)**: 행렬 큐브, 평행 간선 스플래팅, 캑터스트리, 일반화 피타고라스 트리, 힌턴 도표, 연속 산점도, 연속 평행 좌표, 스폿 노이즈, 스트림 리본, 직사각형 카토그램, 이동시간 카토그램, 링 맵, 히스토리 플로
- **전문 도표(7)**: 테일러 도표, 타깃 도표, 노모그램, 파이퍼 도표, 스티프 도표, 스큐-T 로그-P 도표, 하세 도표

전체 360개의 분류별 수(기법·전문 도표·분석 결과·응용 예제)는 아래 4절에 있습니다.

## 2. 구현 수준과 가장 가까운 기존 차트

| id | 구현 수준 | 가장 가까운 기존 차트 | 인코딩이 다른 점 |
| --- | --- | --- | --- |
| matrix-cube | 구조 보존 단순화 (3D 회전·시간/노드 단면·원본 간선 연결. 셀 집계·정렬 최적화 없음) | adjacency, zame | 시간 축을 가진 3차원 행렬과 단면 변환 |
| parallel-edge-splatting | 구조 보존 단순화 (띠·splatting·시간 범위. 계층 정렬·다중 해상도 없음) | edge-bundling, timearcs | 간선을 시간 띠별 픽셀 밀도장으로 압축 |
| cactus-tree | 구조 보존 단순화 (**배치 규칙은 원문 미확인, 직접 설계**) | spacetree, hyperbolic-tree | 원 면적 = 가중치, 부모 둘레 접촉, 트리 경로 간선 묶음 |
| pythagoras-tree | 구조 보존 단순화 (탈레스 원 위 현 규칙, 정확한 규칙은 원문 미대조) | treemap, gosper-map | 정사각형 가지가 뻗는 형태로 계층 가중치 표현 |
| hinton-diagram | 충실한 재현 (면적 ∝ \|값\|). **원 서지 확인되지 않음** | heatmap | 색이 아니라 면적으로 크기, 색은 부호 |
| continuous-scatterplot | 구조 보존 단순화 (2D→2D 선형 보간만, 질량 보존 검증) | scatter, hexbin, kde2d | 점이 아니라 보간한 필드를 속성 평면으로 옮긴 연속 밀도 |
| continuous-parallel-coordinates | 구조 보존 단순화 (해석적이 아닌 삼각형 내부 표본으로 선분 밀도 근사) | parallel | 선 겹침이 아니라 필드 분포의 밀도 |
| spot-noise | 구조 보존 단순화 (직선 타원 반점, 휘는 반점 없음) | ibfv, line-integral-convolution | 벡터장에 맞춰 늘어난 반점의 합 |
| stream-ribbons | 구조 보존 단순화 (와도 접선 성분 ½의 비틀림, 가림 처리 없음. **원 논문 미조사**) | streamtube, stream-surface | 리본 방향 자체가 회전을 나타냄 |
| rectangular-cartogram | 구조 보존 단순화 (재귀 분할 + 무작위 탐색, 이웃 보존은 원 방법보다 약할 수 있음) | cartogram-contiguous, tile-grid | 모양을 사각형으로, 면적 정확 비례, 이웃 보존 지표 |
| travel-time-cartogram | 구조 보존 단순화 (방사형 거리 카토그램. **원 논문 미확인**) | isochrone, cartogram-contiguous | 지도 자체가 이동시간에 맞게 재배치 |
| ring-map | 구조 보존 단순화 (**배치 규칙 원 문헌 미확인, 직접 설계**) | choropleth, radial-bar | 지도 둘레 부채꼴 칸의 동심 고리가 시점 |
| history-flow | 구조 보존 단순화 (구간 ID가 주어진 자료, 텍스트 비교 없음) | alluvial, sankey | 구간의 계보 띠와 저자 색 |
| taylor-diagram | 충실한 재현 (코사인 법칙 위치, 정규화, 음의 상관 반원) | scatter, qq | 상관·σ·RMSD를 극좌표 한 점으로 |
| target-diagram | 구조 보존 재현 (정의는 요약에 의존, 본문 미대조) | taylor-diagram | 편향 대 부호 있는 중심화 RMSD |
| nomogram | 충실한 재현 (로지스틱 점수 눈금·총점-확률 변환) | forest, decision-curve | 계산 도표: 점수 눈금과 총점 변환 |
| piper-diagram | 구조 보존 재현 (두 삼각형과 마름모, K 분리·원 크기 없음) | ternary | 세 좌표를 합친 시료 한 점 |
| stiff-diagram | 구조 보존 재현 (세 행, 네 번째 행 없음) | radar, ternary | 좌우 이온 쌍의 다각형 |
| skew-t | 구조 보존 재현 (CAPE·바람 막대 없음. **원 출처 미조사**) | polar-plot, line | 기울어진 등온선·로그 기압·단열선 체계 |
| hasse-diagram | 충실한 재현 (이행적 폐쇄·축약·순환 검사. **원 출처 미조사**) | dag-layout | 순서 공리 검증·피복 관계·상한/하한 강조 |

**방법론 수와 독립 인코딩 수**: 새 항목 중 `taylor-diagram`과 `target-diagram`은 ‘모형 성능을 한 평면에 요약’이라는 목적을 공유하지만 서로 다른 통계량을 서로 다른 좌표로 그립니다. `piper-diagram`과 `stiff-diagram`은 같은 수질 자료를 서로 다른 인코딩(삼선 좌표 vs 이온 쌍 다각형)으로 그립니다. **`hasse-diagram`은 독립성이 가장 약합니다**: 일반 DAG 배치(`dag-layout`)와 배치 알고리즘이 겹쳐 요청문의 규칙대로라면 ‘DAG 실험실의 부분순서 모드로 통합하고 신규에 세지 않는’ 후보일 수 있습니다. 이 문서는 이행적 축약·순서 공리 검증·상한 하한 강조를 고유하다고 판단해 별도 항목으로 세었으므로, 이 항목을 빼면 **360이 아니라 359**입니다.

## 3. 이전 구현의 정확도 개선 (이번 버전)

| 대상 | 변경 | 검증 |
| --- | --- | --- |
| 백플롯 (bagplot) | 가방을 ‘깊이 큰 절반 점의 볼록 껍질’에서 **깊이 영역 D_k**(모든 방향의 반평면 {u·x ≤ k번째로 큰 u·p}의 교집합)로 교체 | 단위 테스트: 가방이 절반 이상의 점을 담음, 가장 깊은 점들을 포함, 한 정사각형 예의 D₁ 면적 100 |
| 확률적 등치선 | 칸마다 독립이던 노이즈에 **공간 상관 길이**(가우시안 커널 평활 후 분산 1로 정규화) 추가 | 단위 테스트: 상관 길이가 클수록 이웃 상관이 커지고 분산 ≈ 1, 상관 0이면 이전 결과와 동일 |
| 스페이스트리 | 노드 위치 이동에 0.3초 전환(동작 줄이기 설정이면 끔) | 빌드·e2e (애니메이션 자체는 수치 테스트 없음) |

개선하지 못한 것: 컨투어 트리(지속성 단순화·큰 격자 성능), 윤곽 상자그림(원 논문의 상자 확대 울타리), ZAME(전환 애니메이션·계층 탐색), 이센트릭 라벨링(충돌 회피). 이 항목들은 이번 버전에서 손대지 못했습니다.

## 4. 전체 360개 분류별 수

(아래 표는 `kindTotals`로 계산한 값입니다.)

| 분류 | 개수 |
| --- | --- |
| 기법(technique) | 209 |
| 전문 도표(specialized) | 90 |
| 분석 결과(analysis) | 53 |
| 응용 예제(application) | 8 |

이 분류는 항목마다 주분류 하나로 센 값입니다(`kindTotals`). 이전 분류를 임의로 바꾸지 않았고 새 항목 13개를 기법으로, 7개를 전문 도표로 추가했습니다. 이 표의 ‘기법’ 수 209는 범용 표현 방법론의 수와 같은 뜻이 아니며(기법 안에 확장·변형이 섞여 있음), 엄격히 독립적인 표현 원리의 수는 별도로 세지 않았습니다.

## 5. 홈 애니메이션 · 비교 프리셋

- 홈 애니메이션 90 → **100단계** (힌턴, 테일러, 파이퍼, 피타고라스, 캑터스트리, 히스토리 플로, 하세, 노모그램, 연속 산점도, 직사각형 카토그램). 모두 앱의 계산 엔진이 시드 데이터로 계산하며 별도 청크로 지연 로딩합니다. 연속 산점도 단계는 윤곽선(d3.contours)으로 밀도를 보입니다.
- 비교 프리셋 67 → **78개** (새 11개, 목표 75개 이상 달성). 각 프리셋은 한 데이터셋을 모든 차트가 변환 없이 쓰며 테스트로 검증합니다.
- **데이터 공유와 연결(linking)**: 새 프리셋 중 행 단위 연결이 실제로 동작하는 것은 `water-diagrams`(파이퍼 ↔ 스티프, 같은 시료 행), `signed-matrix`(힌턴 칸 ↔ 원본 행; 히트맵 쪽 표시는 확인하지 않음), `rect-carto`와 `ring-choropleth`(지역 행을 공유하므로 이론상 연결되나 e2e로는 확인하지 않음)입니다. `dynamic-matrix`는 행렬 큐브의 2D 단면에서만 원본 간선 행을 연결합니다. 테일러·타깃(통계 요약), 스폿 노이즈·벡터장(필드), 스트림 리본(유선) 등 집계·필드 기반 차트는 데이터 공유일 뿐입니다.
