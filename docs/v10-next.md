# VizLab v1.0 이후 — 남은 과제

v1.0에서 목표를 채우지 못했거나 하지 않은 일을 우선순위 없이 적는다.

## 목표 미달·미수행

1. **후보 조사 50개 이상**: 실제로 웹 검색한 새 후보는 약 24개였다. 더 조사해 후보 풀을 넓힐 것.
2. **구현 20개(목표 20~30, 확장 목표 350+)**: 20개만 구현했다. 350+는 못 채웠다.
3. **이전 구현의 정확도 개선**: 하지 않았다. 단순화한 이전 구현(예: 확률적 등치선의 독립 가정, 이전 버전 위상·세트 계열의 근사)을 논문 정의에 더 가깝게 만드는 작업이 남았다.
4. **10,000노드 측정**: 네트워크 데이터셋 슬라이더 상한이 3,000이라 못 쟀다. 상한을 올리고 Worker의 위치 전송·캔버스 다시 그리기를 측정할 것.
5. **3D/WebGL 평가**: 하지 못했다. 큰 3D 장면에서 캔버스 그리기와 WebGL을 같은 조건으로 비교 측정할 것.
6. **카탈로그 메타데이터 지연 로딩**: 메인 청크에서 카탈로그 정의가 차지하는 비중이 크다. 카테고리별로 분리해 필요할 때 불러오면 첫 로딩 전송량이 줄어든다(이번 버전의 react-vendor 분리는 재방문 캐시 이득만 준다).
7. **연결(링크) 하이라이트 확대**: 이번에 행 단위로 연결한 새 차트는 백플롯과 걸린 루트그램 둘뿐이다. 줄기-잎·스플래터플롯·지니 등은 같은 데이터셋을 공유할 뿐 호버가 다른 차트로 전달되지 않는다(데이터 공유와 연결은 다르다).
8. **서지 직접 확인**: 원문을 읽지 못해 ‘확인되지 않음’으로 남긴 항목(이센트릭 라벨링 DOI, Atom DOI, Tukey 1977, Lorenz 1905, 토네이도 차트, 윤곽 상자그림의 정의 세부 등)을 도서관·출판사 사이트에서 확인할 것.

## 기법별 후속 개선

- 컨투어 트리: 지속성 기반 단순화를 논문 수준으로, 큰 격자(현재 6,000점 이하)에서의 성능.
- 윤곽 상자그림: 원 논문의 상자 확대(inflation) 울타리와 영역 단위 수정 띠 깊이.
- 백플롯: 정확한 깊이 윤곽(깊이 영역의 볼록 껍질)과 점 수가 많을 때의 더 빠른 깊이 계산.
- 스페이스트리: 노드 이동 애니메이션, 카메라 이동, 검색·필터.
- 이센트릭 라벨링: 라벨 겹침 최소화 배치, 마우스 이동에 따른 연속 갱신 보정.
- 단위 시각화: UnitoPia 원 논문을 찾으면 포함-채움(contain-and-fill) 모형 추가.
- ZAME: 클러스터 펼치기 애니메이션, 원 논문의 클러스터링.

## 검증

- 실제 모바일 기기 검증: 이 프로젝트의 ‘모바일’ 테스트는 모두 Chromium의 Pixel 7 **에뮬레이션**이다. 실기기(iOS Safari 등)에서는 확인하지 못했다.
- CI에서의 e2e 성공 여부는 푸시 후 GitHub Actions 결과로만 확정된다(로컬 통과와 CI 성공은 다르다).
