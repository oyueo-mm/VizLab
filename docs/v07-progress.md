## 테스트

- 단위 테스트: 모든 신규 엔진에 수학적 성질 검증이 있습니다(`src/stats/v7*.test.ts`).
  - RadViz: 한 변수만 큰 점은 정확히 그 앵커 위, 동일값은 앵커 중심, 가중 평균 정의와 일치.
  - Grand Tour: 모든 시각에서 정규직교, 같은 시드 재현, 정사영은 길이를 늘리지 않음.
  - 분위수 점도표: 구간 안 점 비율이 구간 확률과 1/n 이내.
  - HOPs: 같은 (시드, 장면) 재현, 표본 평균·분위수가 t 표본분포와 일치.
  - 시간 곡선: 고전적 MDS가 평면 배치의 모든 쌍 거리를 보존.
  - 마레이: 선분 교점 공식과 추월 검출. 선형 집합 도표: 열 너비 합 = 1, 집합 크기 = 포함 열 너비 합.
  - 보로노이 트리맵: 면적 오차, 외곽 포함, 시드 재현. 탱글그램: 교차 = 순열의 역전 쌍, 뒤집기 정렬이 같은 트리를 0으로.
  - 쌍곡 트리: 뫼비우스 변환이 쌍곡 거리를 보존, 깊이 k = 거리 kδ.
  - FDEB: 호환성 성질, 끝점 고정, 묶음 후 중간점 거리 감소, 다른 줄기는 합쳐지지 않음.
  - LIC: 수평 흐름에서 흐름 방향 이웃 대비가 수직 방향의 45% 미만(수직·대각·소용돌이도 검증).
  - 3D 지구본: `d3.geoOrthographic`과 같은 좌표(6자리), 가림 판정, 역변환. MPR: 세 단면이 직접 보간과 일치.
- 합계: 단위 테스트 646개(기존 570개 유지 + 신규 76개), 브라우저 테스트 373개(전체 실행: 367개 통과 + 수정한 6개 재실행 통과)(기존 349개 + 신규 24개 `e2e/v7.spec.ts`).
- 분류 회귀: 기존 250 ID와 설명이 모두 존재, 모든 항목이 정확히 하나의 주분류, 합계 일치, 성격×카테고리 필터 조합, 양방향 연결, URL 왕복.

## 불안정했던 테스트의 원인

비교 실험실의 ‘KDE 폭 변경이 히스토그램 구간을 바꾸지 않는다’와 ‘공유 데이터 편집’ 테스트는 막대 그려지기 전에 `count()`를 한 번만 읽는 비재시도 읽기(렌더 직후 0을 읽음)가 원인이었습니다. 앱의 저장·상태 복원 경쟁은 아니었습니다. 막대가 보일 때까지 기다리고(`expect.poll`) 읽도록 고쳐 12회 반복 실행에서 24/24 통과했습니다.
